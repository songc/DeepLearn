# 数学公式与文本排版规则

## 核心要求
当前聊天界面不支持 LaTeX（KaTeX / MathJax）公式渲染。所有数学公式必须避免使用 `$ ... $` 或 `$$ ... $$` 语法。

## 具体执行规则
1. **行内公式**：使用纯文本和 Unicode 符号，如 `ln(y_hat)`, `x^2`, `y_i`, `∑`, `∏`, `×`, `∂`。
2. **块级公式**：统一使用 `text` 语言标记的代码块呈现，例如：
   ```text
   softmax(x)_i = exp(x_i) / sum(exp(x_j))
   Loss = - ln(y_hat)
   ```
3. **矩阵与分布**：使用清晰的文本或 Python 张量示例说明，严禁使用 `\begin{bmatrix}` 等 LaTeX 矩阵语法。
